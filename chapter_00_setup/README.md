# 🛠️ Chapter 00 — Setup

Before we write a single `print("Hello World")`, let's set up our workspace the right way.

Most beginners skip this chapter and jump straight into code. Don't. A messy setup causes 90% of "it works on my machine" problems later.

## 📂 What's in this chapter

| File | What you'll learn |
|---|---|
| `01_venv_create.md` | The classic way to create a Python virtual environment (`venv`) |
| `02_uv_package_manager.md` | 🚀 `uv` — a much faster modern tool that replaces `venv` + `pip` |
| `03_requirements_freeze.md` | How to save & share your project's dependencies |
| `04_gitignore.md` | What NOT to upload to GitHub |

## 🤔 Why does this matter?

Every chapter after this one assumes you have a clean virtual environment running. Skipping this now means chasing weird errors later — trust me, future-you will thank present-you 🙏
